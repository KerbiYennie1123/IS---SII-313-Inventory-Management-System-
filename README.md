# Inventory Management System

A CRUD-based Inventory Management System for computer parts, made as a Windows desktop application.

## Final Term Activity #1

The activity focused on designing an Inventory Management System based on a client scenario.

For the initial design, I created a **one-page physical drawing on bond paper** that focused on the **Inventory Edit section**. The drawing mainly showed how the CRUD functions would work when managing inventory records.

The physical drawing was only the initial idea. When developing the actual application, some parts were changed or improved based on the development process.

## CRUD Functions

- **Create** - Add new products
- **Read** - View inventory records
- **Update** - Edit product information
- **Delete** - Remove records

## System Development

The design was then developed into a working Windows desktop application using **C# and .NET 10 with WPF**. **Microsoft Access** was used to store the system's data.

The current application follows the main idea of the original drawing, but it is not an exact copy. The system is still under development, so its design and features may change over time.

## Arki Computer Parts

The current system is called **Arki Computer Parts**. It is designed to manage computer parts and their inventory records.

### Main Features

- Dashboard
- Product management
- Product images
- Stock In and Stock Out
- Supplier management
- Category and brand management
- Inventory reports
- CRUD operations

## Technologies Used

- C#
- .NET 10
- WPF (Windows Presentation Foundation)
- Microsoft Access
- Visual Studio Code
- Inno Setup
